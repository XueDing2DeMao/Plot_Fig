# Plot Fig

面向科研绘图的本地 Web 编辑器。通过导入表格数据、绑定数据列、编辑图层与坐标轴，生成可继续编辑的图形项目，并导出用于文档和论文的图片。

项目采用 TypeScript、React 19 和 Vite，使用 pnpm workspace 管理图形模型、数据绑定、SVG 渲染、版本迁移与编辑器。日常编辑和 SVG / PNG 导出在浏览器中完成。

## 快速开始

### 环境要求

- Node.js **24.13.0 或更新版本**。
- pnpm **11.19.0**，与根目录 `package.json` 的 `packageManager` 声明一致。
- 支持现代 Web API 的浏览器。

安装指定版本的 pnpm：

```bash
npm install --global pnpm@11.19.0
```

克隆仓库、安装依赖并启动编辑器：

```bash
git clone https://github.com/XueDing2DeMao/Plot_Fig.git
cd Plot_Fig
pnpm install --frozen-lockfile
pnpm --filter @plot-fig/web-editor dev --host 127.0.0.1 --port 5173
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:5173`。如果端口被占用，以 Vite 实际输出为准。

### Windows 启动脚本

安装 Node.js 和 pnpm 后，可以直接双击根目录的 `start-plot-fig.cmd`。脚本会检查环境、按锁文件安装依赖，并启动服务和浏览器。

也可以在 PowerShell 中运行：

```powershell
# 仅检查环境并安装依赖
.\start-plot-fig.cmd --check

# 启动服务，但不自动打开浏览器
.\start-plot-fig.cmd --no-open
```

在运行服务的终端按 `Ctrl+C` 停止。

## 基本使用流程

1. **导入数据**：选择或拖入一个或多个 CSV / TSV / TXT / XLSX，也可粘贴表格。检查分隔符、表头、单位行和数据起始行。
2. **绑定数据**：选择数据表，为曲线指定 X、Y 或当前图表需要的数据角色；按需增加曲线或图层。
3. **调整图形**：通过图形设置和对象属性编辑坐标轴、线条、符号、图例、标注及图层布局。
4. **检查预览**：查看图形预览与诊断信息。更换数据或绑定后检查坐标范围及缺失值提示。
5. **保存项目**：下载 `.plotfig.json`，下次通过项目文件入口重新打开。刷新或关闭页面前保留最新项目文件。
6. **导出图片**：选择 SVG / PNG，或按图层批量导出 ZIP。替换多张数据表时，使用预览工具栏“模板”分组的“数据表批绘”入口。

可使用 [`tests/fixtures/web/p2-a.csv`](tests/fixtures/web/p2-a.csv) 或 [`tests/fixtures/web/p2-workbook.xlsx`](tests/fixtures/web/p2-workbook.xlsx) 体验数据导入。

自定义模板保存在当前浏览器的 IndexedDB 中。跨设备迁移或清理浏览器数据前，请导出需要保留的模板。

### 导入 Origin 原生绘图模板

在“模板中心 → 我的模板 → Origin 原生模板”选择 `.otp / .otpu` 文件（最多 16 MiB）。编辑器调用本机安装的 Origin，读取页面、图层、坐标轴以及可支持的绘图样式。转换后先查看示例图和兼容提示，再点击“保存导入模板”；新模板会自动选中，随后可选择“仅样式”或“完整模板”并绑定自己的数据。

原生导入需要 **Windows 和可正常启动的 Origin**，通过上文的本机 Vite 开发服务或 `pnpm --filter @plot-fig/web-editor exec vite preview --host 127.0.0.1` 使用。只部署静态网页时没有本机转换接口；既有 JSON 模板导入和普通绘图仍可使用。导入在本机处理，服务只接受回环地址的同源请求，最多同时转换一个文件，并支持取消和超时清理。

当前映射折线、散点、线加符号、柱条图和面积图及可支持的堆叠设置。复杂图型、分组、特殊标注、字体或格式无法等价转换时会显示兼容提示；没有可支持绘图的模板会拒绝导入，不保证所有 Origin 模板无损还原。含可执行脚本、自定义表达式或需要求值标签的模板会拒绝导入。导入仅操作独立 Origin 会话，不使用已经打开的用户项目；保存模板本身不会替换当前图形。

### 批量导入数据文件

在“导入数据 → 选择文件”中按 Ctrl / Shift 多选文件，或将多个文件一起拖入。支持混合 CSV、TSV、TXT、XLSX；每批最多 50 个文件、合计 100 MiB，单文件仍限 10 MiB。文件在本地处理。

所有文件在同一个窗口预览。默认勾选每个文件的第一张数据表；Excel 可追加勾选其他工作表。点击对应“预览”可分别设置表头、单位行和数据起始行；编码和分隔符应用于本批所有文本文件，修改后会重新读取并重置表选择和行设置。自动检测按文件分别识别编码和分隔符。

损坏、超限或格式不支持的文件会列出名称与原因，其余有效表仍可一次“确认导入”。取消不会追加数据；确认后进入待绘图设置，点击“生成图形”或“应用修改”后生效。同名文件分别追加，已有数据保留；整批应用可一步撤销。工作区仍限制 1,000,000 单元格，追加失败时可减少勾选的表后重试。导入完成后，可在预览工具栏“模板”分组继续“数据表批绘”。

### 批量绘图

预览工具栏“模板”分组提供“数据表批绘”，使用当前图形或所选模板为多张数据表绘图；“导出图形”中的按图层导出继续用于当前图形的各图层。

- **按数据表**：打开“数据表批绘”后，默认以“当前已应用图形（直接批绘）”为绘图依据，选好已导入的数据表即可开始批处理，无需保存或将当前图形设置为模板。每项只绑定一张表。若有待绘图设置，先应用或重置，再进入批处理；模板库中的模板仍可按需选择。
- **模板与映射**：可选择“仅样式”或“完整模板”。数据表批绘默认开启“自动识别两列 XY”：优先手动选择和同名列，再识别 X/Y 表头，仍无法匹配时按第一列 X、第二列 Y；X 支持数值、日期和日期时间，Y 必须为数值。单图层同坐标轴的多条 XY 曲线换到两列表、原绑定无法完整匹配时，自动保留第一条曲线及其样式，避免重复绘制同一 Y 列；映射区会显示说明，可关闭自动识别恢复严格列名匹配。多列数据、复杂图形、重复列名和类型错误仍需明确映射。完整模板的必需槽必须有有效映射；原图依赖多张表时，按表批次需要逐项确认全部映射。未配置项记录失败，已配置项仍可输出。
- **复用格式**：默认直接沿用当前图形格式，也可立即选择“所有样式格式”“所有格式”“自定义格式”，不必先选择模板。选择其他模板后，“仅样式”中的“模板默认格式”沿用原有模板样式套用方式。自定义可多选页面背景、已有图层图例格式、图层背景、图层尺寸、刻度与范围、颜色、字体；未选项目保留当前图形设置。图层按顺序对应所选图形，来源图层不足时循环复用；尺寸保留目标位置，刻度范围保留目标轴标题。默认换表后按当前重缩放策略适配数据，勾选“刻度与范围”或“所有格式”则复用来源图形范围。预览、图片和可重开的项目使用相同选择，修改选择后需重新运行批次。“完整模板”仍复用整个模板的结构和格式。
- **执行与下载**：选择 SVG、PNG 和是否包含可重开的项目；运行时锁定配置，支持取消、重试失败或取消项、下载已完成文件 ZIP。重试保留已成功文件；修改配置会清空旧结果。ZIP 使用序号和净化文件名，并包含 `manifest.json`。
- **窗口布局**：左侧按数据选择、绘图格式、列映射、输出分组，表名单限高滚动；自动 XY 与 SVG/PNG 开关直接可用，手动映射及更多输出设置按需展开，收起时保留状态摘要。待配置项会自动展开映射区，默认定位异常项目。右侧图形等比适配预览区域，可用上一项、下一项或下拉框切换项目。正常预检默认收起，出现待配置项时自动展开；批次明细可收起并保留结果汇总。窄屏优先显示预览，底部操作始终可用。

批处理不修改当前工作区。直接沿用当前图形时，同一数据表保留当前可见的坐标轴范围，不因打开批量预览而重新缩放；相关数据变化时才按轴的重缩放策略适配。自动识别时，自动坐标轴标题随新列名更新，手动填写的标题保持原样。预览和导出使用相同的数据范围：默认未抽稀数据，显式开启“导出抽样”时沿用该设置，并保留数据视图和子集限制。每批最多 50 项，输入不超过 100 MiB，输出不超过 200 MiB；批次状态不跨会话保存。

### 自动保留与恢复草稿

项目文件区默认开启“自动保留恢复草稿”。生成图形或应用修改后，停止编辑 2 秒自动保留；持续修改时每 30 秒内发起一次保存尝试。未应用的绘图设置、属性输入和撤销历史不写入草稿。后台页面可能受到浏览器计时限制。

刷新或重新打开页面后，可在“恢复草稿”中选择副本，也可“本次跳过”。恢复会清空撤销历史并保留未下载提醒；仍请用“保存项目”下载 `.plotfig.json`。自动保留与手动下载各自维护状态，下载不会删除恢复副本。

同一站点最多保留 3 份草稿，单份不超过 20 MiB，总载荷不超过 60 MiB。不同标签页、打开其他项目以及恢复后继续编辑使用独立副本；满额时先在恢复窗口逐条清理，不自动淘汰旧记录。删除当前副本后，需点击“重新保留当前工作区”才会再次创建。

关闭开关会同步到同站点其他标签页并保留已有草稿，关闭后仍可恢复或删除。草稿只在此浏览器中保存，不跨设备同步；清除站点数据会移除草稿。存储不可用或写入失败时，编辑、手动下载和 SVG/PNG 导出仍可使用。

### 批量选择 Y 数据列

导入含多个 Y 列的数据表后，在“数据绑定”中点击“批量选择 Y 列”，选择共用的 X 数据列并勾选需要绘制的数值 Y 列。窗口支持按列名搜索、全选搜索结果和清空选择；X 列不会出现在 Y 列列表中。

点击“添加所选曲线”后，再点击“生成图形”或“应用修改”。曲线按数据表原列顺序添加到当前图层，图例名称跟随 Y 列名；已有曲线保留，相同坐标轴上的相同 X/Y 绑定会跳过。支持折线、散点、柱形（含堆叠）和面积图，原始表格不变。取消窗口不修改绑定，尚未应用时也可用“重置待绘图设置”撤回整批添加。

### 矩阵热图

对于“首列坐标 + 多列强度”的宽表（例如多组 XRD 数据），导入后先将当前图层的“图表类型”设为“热力图”，再在“数据绑定”中点击“矩阵热图”。该入口仅在热图类型下显示：

1. 选择数据表、坐标列和需要的强度 Z 列，支持搜索、全选和指定数据行范围。
2. 选择“Y 数据跨列”时，每个强度列沿 Y 轴排列，坐标列作为 X；选择“X 数据跨列”可交换布局。
3. 跨列坐标可使用所选列序号、数值列名、数值单位行、指定工作表行或自定义数值。文本列标签请使用列序号或另填数值坐标；坐标必须有限且不重复。
4. 在“颜色映射”中选择 Viridis、Plasma、Inferno、Magma、Coolwarm、Blues、YlGnBu、Spectral 或灰度预设，渐变条按低值到高值预览。可反向色阶、设置自动或固定 Z 范围、选择线性或 Log10 映射及连续或分块颜色；展开“自定义色阶”可逐个调整颜色，也可设置颜色条标题与单位。
5. 点击“生成热图”，创建独立图层，保留原表和已有曲线。热图使用生成时的数据快照；修改原表后需要重新生成。

生成后，在“图形属性”中选择热图曲线，打开“颜色映射”页可继续更换配色；三列 X/Y/Z 热图也可使用此入口。颜色设置随项目保存，并用于图形预览和图片导出。Log10 映射只适用于正值，固定范围须满足最小值小于最大值。

矩阵入口最多支持 **99,999 个单元**，覆盖 800 行 × 94 列的完整矩阵。缺失强度保持空白，非等距坐标按相邻中心的中点划分单元，也支持单行或单列。生成后可缩放、保存项目并导出 SVG / PNG。

原有三列 X/Y/Z 热图绑定继续可用，矩形网格上限为 100,000 个位置。不要将两列独立光谱强度分别当作 Y 坐标和 Z 值；这种绑定会把不同 X、Y 值组合成庞大的稀疏网格。等高线仍要求完整等距网格，上限为 40,000 个位置。

### 曲线组

在“图形属性”窗口选择图层或 XY / 面积曲线，打开“组”页，点击“添加曲线组”，将当前图层中共用 X/Y 坐标轴的未分组曲线加入新组。

- **从属**：按组成员顺序递增颜色、线型和符号，可选择内置色列、设置同步 / 嵌套递增及步长，展开“自定义递增列表”逐项编辑。
- **成员管理**：勾选加入或移出成员，拖动成员或使用上移 / 下移按钮调整样式递增顺序；不改变数据行顺序。每组至少保留一条曲线，同一曲线只能属于一个组。
- **独立 / 解除分组**：保留当前外观后独立编辑。数据列映射和单点样式优先于组样式。
- **子组关系**：支持为同坐标轴上的组手动指定父组，防止循环嵌套；当前未提供按大小、列标签或坐标轴自动划分子组。

组名称、成员顺序和样式设置随项目保存，应用后用于预览与导出；取消窗口可撤回尚未应用的修改。“堆叠”保留为独立标签页。

### 曲线组颜色与 Colormap

“组 → 线条颜色”提供两类着色机制，选择同一调色板时也有不同含义：

- **逐个循环 / 拉伸色列 / 分箱色列**：按成员序号分配离散颜色。逐个循环用完色列后重复；拉伸覆盖首尾颜色；分箱选取各箱中间的列表颜色。
- **数值映射**：整条曲线按连续色带着色。来源可选“曲线序号”或“每条曲线的数值参数”。例如温度为 500、550、1000 的三条曲线，会按实际温差取色，不会均匀分成三种颜色。

数值参数可逐条输入或批量粘贴（空格、逗号、分号、换行分隔），支持参数名称 / 单位、自动范围、固定范围和反转色带。固定范围输入后点击“设置映射范围”。范围外取端点颜色；所有数值相同时取色带中点；缺失参数保留基础颜色并显示提示。参数绑定曲线 ID，重排不改变其归属。设置随项目保存，旧项目未设置此项时仍使用原递增行为。

勾选“显示组色标”后，图层右侧显示本组的连续色标，复用相同的色带、范围和反转设置。默认关闭；只对从属组中实际可绘制的映射曲线显示。色标通常有最小值、中点、最大值三个刻度；等值范围使用中点颜色和一个刻度。“参数名称／色标标题”未设置时使用组名，显式留空可隐藏标题，也可点击“色标标题使用组名”恢复默认。多个组色标与热图色条分别占位，多轴叠加和共享 X 堆叠保持绘图区对齐；空间不足时会提示扩大图层、缩短标题或关闭部分色标，并阻止应用。设置随项目和完整模板保存，用于 SVG、PNG 和批量 ZIP 导出；仅样式模板保留目标图形原有的组配置。

也可选择“从数值列名读取参数”：根据每条曲线的 Y 数据绑定，预览原始列名和读取结果，再点击“写入 N 个参数”。支持完整有限十进制数（含小数、正负号、科学计数法及首尾空白）；`Sample_01`、带单位文本、空列名或无有效绑定会显示错误，并保留该曲线原参数。读取只更新属性草稿，点击“应用”或“确定”后生效，取消可放弃。这是一次性取值，修改列名不会自动更新参数，需要重新读取；读取后仍可逐条编辑。预览期间列名或成员发生变化时，需重新读取后再确认。

单条曲线内部的数据点着色仍在“线条 → 线条颜色映射”中设置：按原行递增、连续数据列映射和分类映射彼此区分。更换调色板保留已选择的映射方式、绑定及范围。该按点映射优先于曲线组颜色。“线条颜色 → 按曲线 → 组与数值映射…”可跳转到组设置。

当前每曲线参数保存为显式数值；尚不读取 Origin 的工作表自定义列标签行，也不持续绑定列名。

### 曲线堆叠与偏移

在“图形属性”窗口中选择左侧图层，再打开“堆叠”页。折线、散点及面积曲线支持以下模式：

- **无**：清除该图层的曲线偏移和累积堆叠，恢复原始数据位置。
- **累积**：同坐标轴、线性 Y 轴上的曲线按正负值分别累计；可选择百分比堆叠、成员和总计标签。
- **常量**：按可见曲线顺序偏移 `0、d、2d…`，`d` 使用对应轴的数据单位，支持负数。
- **自动**：使用整层可见曲线的最大数据跨度及附加间距依次错开，默认间距为 8%，适合批量 XRD 曲线。
- **单独**：选择一条曲线，分别设置 X/Y 偏移。由常量或自动切换时保留当前偏移位置。

常量和自动模式可选 X、Y 或两个方向。设置只改变绘图显示及范围，不修改原数据；点击“应用”或“确定”后，主预览、项目保存和图片导出保持一致。固定坐标范围可能裁剪偏移后的曲线，可在坐标轴设置中恢复自动范围。非线性轴按数据值偏移，不进行视觉比例补偿。柱状图的累积显示仍通过“堆叠柱形图”类型设置。

“应用于…”中的“曲线堆叠”会同时复制累积设置和偏移设置；常量/自动作用于目标图层全部曲线，单独偏移按曲线位置对应。多选编辑中的该项用于调整累积成员和百分比模式。

### 多纵轴图的页面空间

显式生成或重新应用双/三/四纵轴预设时，会为左右坐标轴标题与刻度预留页面空间；三/四纵轴的外侧轴默认向外偏移 60 pt。页面过窄、预留后绘图区不足 60 pt 时，应用会提示空间不足，请先增大页面宽度。切回单轴时恢复预设前的图层区域。

直接打开旧项目保留原布局；旧四轴图若有裁切，可重新应用预设。特殊长标题、旋转文字或较大字号仍需检查导出并手动调整布局。锁定轴长比例的热图可在有限的小高度内缩小竖向色条；不能输出有效字号的极小尺寸会明确拒绝，组色标仍遵循原有最小空间要求。

### 全局撤销与重做

绘图操作区的“撤销”“重做”作用于已确认的图形与数据修改。每次“生成图形”“应用”“确定”记录一步；支持 `Ctrl/Cmd+Z` 撤销、`Ctrl/Cmd+Y` 或 `Ctrl/Cmd+Shift+Z` 重做。输入框内保留文字自身的撤销；有待绘图设置或打开的属性窗口时，请先应用或取消草稿再操作全局历史。

默认最多保留 100 步，并按共享对象估算控制在 64 MiB 内。达到预算时淘汰最早记录；单步过大仍保留当前结果，但提示该步无法撤销。相同原始数据在历史间共享，历史只驻留内存；重新打开项目会清空历史，撤销后再修改会清除旧重做分支。

撤销会精确恢复数据绑定、图层、注释和坐标范围；回到最近手动保存的内容时取消未保存提示。保存会中断滚轮事务合并，确保保存点可以撤销到达。“撤销缩放”仍只操作当前缩放会话，并作为一次全局事务；全局撤销或重做后重置局部缩放会话。

### 直接移动图例与文字

在预览中按住图例或文字注释拖动，松开后确认位置；每次拖动只记录一步全局撤销。选中后用方向键移动 1 个屏幕 CSS 像素，按住 Shift 移动 10 个像素，按当前预览显示比例换算。拖动中按 Esc、失去指针捕获、切换图层或调整浏览器窗口大小会取消本次移动。

支持页坐标和图层坐标的图例、文字注释，默认图例首次移动后转为可保存的图例，并保留当时显示的条目。位置随项目保存、恢复草稿和 SVG / PNG 导出。双击图例文字仍可修改曲线名称；双击文字注释后，在图页属性的“注释”页编辑内容或坐标。数据坐标注释继续通过该属性入口调整。

“框选放大”模式下拖动用于缩放；有待应用绘图设置或打开属性窗口时，请先应用或取消后再移动注释。输入框中的方向键仍用于文字编辑。

### 预览工具栏

图形预览上方按“编辑、图形、模板、格式、图层、视图”分组排列功能键，窄屏自动换行。撤销/重做与放大/缩小使用图标，悬停可查看功能和快捷键；图形属性、坐标轴、图层管理及批处理仍有直接入口。“操作提示”可展开查看滚轮、键盘和图例/文字移动说明；操作错误与当前状态仍直接显示。

### 图形放大与缩小

在预览绘图区滚动鼠标滚轮可缩放 X 轴；按住 Shift 缩放 Y 轴，按住 Ctrl（macOS 为 ⌘）同时缩放两轴。鼠标位于坐标轴上时，只缩放该轴。绘图区外仍正常滚动页面。

工具栏提供“放大”“缩小”“框选放大”“撤销缩放”和“恢复初始范围”。框选模式下拖出矩形放大局部，按 Esc 退出；绘图区获得焦点后，也可用 `+` / `-` 缩放、`Alt+Backspace` 撤销、`Home` 恢复。连续滚轮操作会合并为一步撤销，最多保留 100 步；重新打开项目、修改数据或手动改轴范围后开始新的缩放历史。

缩放会改变坐标轴显示范围，并用于项目保存和图片导出；原始数据不变。分类柱图按类别窗口放大，保留类别顺序、标签和柱间距比例；分类轴属性中的范围按类别带边界计算，例如 `0–3` 显示前三个类别。恢复初始范围返回本轮缩放前的窗口；分类轴属性中的“恢复自动范围”显示全部类别。旧项目的自动范围保持兼容，保存了分类轴局部范围的新项目需要本版编辑器打开。

线性、对数和 SymLog 等连续数值轴支持鼠标锚点缩放；断轴和离散数值轴仍通过坐标轴属性调整。锁定 X:Y 数据比例时使用双轴同比例缩放，自由框选需先关闭数据比例。共享轴保持联动，违反公式定义域或轴对齐约束的缩放会显示提示并保留原图。

## 格式与使用边界

- 当前图形模板 / 图形文档 Schema 为 **1.23.0**；工作区项目文件版本为 **2.0.0**。二者独立管理。
- 数据文件上限为 **10 MiB**，项目文件上限为 **20 MiB**；表格处理限制为 100,000 行、256 列、1,000,000 单元格。
- Heatmap / Contour 使用规则、等间距的 XYZ 网格；不提供散点到网格的自动插值。
- `origin-compat` 继续处理约定的 Origin Snapshot JSON。模板中心的原生 OTP / OTPU 导入由 Windows 本机 Origin 读取器负责，固定读取程序与模板自身脚本分离；不会把上传内容作为脚本执行。
- `docs/` 中的验收记录反映各自日期的开发状态，部分链接指向作者本地记录。当前行为以源码和本次运行结果为准。
