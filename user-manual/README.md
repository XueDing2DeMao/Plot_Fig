### 1.1 开始使用与环境准备

Plot Fig 是本地科研绘图工作台：将表格中的列绑定到图形对象，调整外观与坐标轴，保存可编辑项目，再导出 SVG 或 PNG。本手册面向当前工作区的可用功能；界面核对日期为 2026 年 10 月 8 日，图形 Schema 为 1.24.0，工作区项目格式为 2.0.0。

> 直接双击本文件夹的 index.html 阅读。目录可跳转，浏览器 Ctrl+F 可搜索全文；图片与示例均为本地文件，整文件夹复制后仍可离线阅读。示例数据均为教学构造数据。

| 环境 | 要求与操作 |
| --- | --- |
| Node.js | 24.13.0 或更新版本；终端运行 node --version 检查。 |
| pnpm | 项目声明 11.19.0；运行 pnpm --version 检查。 |
| 浏览器 | 使用支持现代 Web API 的浏览器；图像生成与普通数据处理在浏览器中进行。 |
| 可选 Origin | 仅导入原生 OTP/OTPU 模板时需要 Windows 与能正常启动的本机 Origin。 |

1. 进入项目根目录。Windows 可双击 `start-plot-fig.cmd`，脚本检查环境、按锁文件安装依赖并打开浏览器。
2. 也可按下面命令启动；以终端实际输出的地址为准。首次安装依赖需要可访问依赖源。
3. 保持服务终端运行；完成工作并下载项目后，按 Ctrl+C 停止服务。

```text
npm install --global pnpm@11.19.0
pnpm install --frozen-lockfile
pnpm --filter @plot-fig/web-editor dev --host 127.0.0.1 --port 5173
```

Windows 脚本参数：`.\start-plot-fig.cmd --check` 只检查环境并安装依赖；`.\start-plot-fig.cmd --no-open` 启动而不自动打开浏览器。常用访问地址为 `http://127.0.0.1:5173`。

### 1.2 工作区导览与操作生效规则

![图 1.1　初始工作区：左侧导航与数据表，中间数据绑定和图形预览，右侧绘图设置与诊断](images/01-workspace.png)

图 1.1　初始工作区：左侧导航与数据表，中间数据绑定和图形预览，右侧绘图设置与诊断

| 区域 | 用途 |
| --- | --- |
| 项目文件 | 打开项目、保存项目、自动保留恢复草稿、恢复已有副本。 |
| 导入数据 | 文件选择、拖入文件、粘贴文本；导入后使用“追加数据”。 |
| 数据表预览 | 查看已导入文件、数据行列、列设置与表名称。 |
| 数据绑定 | 一条曲线对应一组数据角色；不同曲线可来自不同表。 |
| 图形设置 | 切换当前图层的图表类型、线型和标记；生成图形或应用修改。 |
| 预览工具栏 | 编辑、图形、模板、格式、图层、视图六组入口。 |
| 诊断信息 | 显示绑定、数据、范围、布局等问题；按提示修正。 |

#### 先区分四种对象

数据表保存观测值；曲线保存列绑定与绘制外观；图层容纳曲线、坐标轴和布局；图页容纳所有图层及页级文字和注释。一个项目同时保存图页、数据表和绑定。删除数据表、删除曲线、删除图层是不同操作。

#### 改完设置，何时会出现在图片中

1. 导入、改绑定、改图表类型属于待绘图设置。首次点击“生成图形”，后续点击“应用修改”；“重置待绘图设置”放弃这一批尚未应用的更改。
2. 属性窗口中的“应用”提交并留在窗口，“确定”提交后关闭，“取消”放弃尚未应用部分。已经点击“应用”的修改可用全局撤销恢复。
3. 检查“预览已更新”与诊断信息，然后保存项目或导出。下载文件、自动恢复和批绘主要围绕已应用状态工作。

> 菜单或按钮变灰通常表示当前对象、图型或状态不适用。属性对象树选中谁，就编辑谁；不要仅凭页签名称判断修改范围。

### 1.3 十分钟完成第一张双曲线图

目标：使用随附的 [01-xy.csv](examples/01-xy.csv)，以 Time_s 为共同 X，以 Sample_A、Sample_B 为两个 Y。Error_A 与 Temperature 留作进阶练习。

1. 启动编辑器，选择文件 01-xy.csv；或用文本编辑器打开它，复制全部内容后选择“从剪贴板粘贴”→“预览文本”。
2. 确认表头行为 1、单位行为 0、数据起始行为 2。预览应为 5 列、7 个数据行，点击“确认导入”。
3. 检查第一条曲线 X=Time_s、Y=Sample_A。点击“批量选择 Y 列”，共用 X 选择 Time_s，只勾选 Sample_A 与 Sample_B，点击“添加所选曲线”。已有相同绑定会跳过。
4. 图表类型选择“折线图”，线型选择“实线”，符号选择“方形”，点击“生成图形”。
5. 应看到两条曲线：Sample_A 从 0.2 增至 3.1，Sample_B 从 0.3 增至 2.7。若没有图，检查绑定和诊断，再应用。
6. 点击“图形属性”，选择曲线，调整颜色或线宽并确定。点击“保存项目”下载 .plotfig.json。最后打开“导出图形”，预览后导出 PNG 或 SVG。

### 1.4 图表类型选择与数据组织

入口：右侧图形设置 → 图表类型。切换类型可能改变所需数据角色；切换后重新检查绑定，再应用。线加符号通过折线加标记组合得到。

| 图型 | 数据角色 | 适合的操作 |
| --- | --- | --- |
| 折线 / 散点 / 线加符号 | X、Y；可选误差和映射列 | 趋势、相关性；无线条+标记即点图，实线+标记即线加符号。 |
| 柱形 / 堆叠柱形 | 类别、数值；可选误差 | 离散组比较；可切换方向、间距、重叠与基线。 |
| 直方图 | 一列样本值 | 选择分箱方法与归一化，查看分布。 |
| 箱线图 | 样本值；可选分组、分裂分组 | 比较分布、离群点、均值/中位数。 |
| 面积图 | X、Y | 设置填充、基线或曲线间填充。 |
| 热力图 | X、Y、Z，或宽表矩阵入口 | 用颜色表达强度；确认坐标和色标。 |
| 等值线图 | 完整、等间距 X/Y/Z 网格 | 设置等值线级别、填色、线与标签。 |
| 双 / 三 / 四纵轴 | 多组 X/Y 绑定 | 不同量级的数据共享图页；明确各曲线的 Y 轴。 |
| 上下共享横轴 | 多组 X/Y，分层显示 | 横轴对齐而纵轴分别呈现。 |

> 同一图层的图表类型设置会统一该层的绘图类型。多纵轴和共享 X 是结构预设，并非新数据格式。灰色“分格”等保留入口不代表功能已实现。

### 1.5 画布缩放、撤销重做与快捷键

| 操作 | 作用与前提 |
| --- | --- |
| 滚轮 | 绘图区内缩放 X；Shift+滚轮缩放 Y；Ctrl/⌘+滚轮双轴缩放；位于轴上时仅缩放该轴。 |
| 放大 / 缩小 | 使用预览工具栏按钮调整可见数据范围。 |
| 框选放大 | 启用后拖矩形；Esc 退出。锁定数据比例时先检查该约束。 |
| + / − | 绘图区获得焦点后缩放。 |
| Alt+Backspace / Home | 绘图区内撤销缩放 / 恢复本轮初始范围。 |
| Ctrl/⌘+Z | 撤销已应用工作区修改；输入框内保留文本本身的撤销。 |
| Ctrl/⌘+Y 或 Ctrl/⌘+Shift+Z | 重做工作区修改。 |
| Ctrl+O / Ctrl+S | 打开 / 保存项目；输入框与弹窗状态可能阻止快捷命令。 |
| Ctrl+G / F2 / F12 | 导出 / 图页属性 / 图层内容；在合适的图形上下文中使用。 |
| Enter / Esc / Ctrl+Enter | 原位编辑中提交 / 取消 / 提交多行图例。 |

全局历史通常每次生成、应用、确定记录一步；连续滚轮会合并事务。历史最多 100 步，并按共享对象估算控制在 64 MiB，超预算淘汰最早记录；单步过大可能无法撤销但保留当前结果。打开项目清空历史，撤销后进行新修改会清除重做分支。

> 缩放改变轴范围，会进入项目与导出，原始数据不变。“撤销缩放”只对应当前缩放会话；全局撤销可恢复图形、数据、绑定与范围。有属性窗口或待绘图设置时先应用或取消，再使用全局历史。分类图的恢复初始范围不一定等于显示全部类别，显示全部可用轴属性的恢复自动范围。

### 2.1 导入文件、粘贴文本与批量导入

![图 2.1　导入预览：检查分隔符、表头和数据起始行后确认](images/02-import.png)

图 2.1　导入预览：检查分隔符、表头和数据起始行后确认

| 输入方式 | 使用方法 |
| --- | --- |
| CSV / TSV / TXT | 选择文件或拖入；自动识别编码、分隔符。乱码时改 UTF-8、GB18030 或 UTF-16 LE；挤成一列时改逗号、Tab、分号或连续空格。 |
| XLSX | 选择工作簿，勾选要导入的工作表；可只选部分工作表。 |
| 粘贴表格 | 从 Excel 复制含表头区域，粘贴后先“预览文本”；确认分列正确再导入。 |
| 多个文件 | 文件选择中按 Ctrl/Shift 多选，或一次拖入多个文件。支持混合文本与 XLSX。 |

#### 行设置

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| 表头行 | 从 1 开始；0 表示没有表头 | 第一行为名称时填 1 |
| 单位行 | 独立单位行；0 表示无单位行 | 第二行为 s、MPa 等时填 2 |
| 数据起始行 | 从该原始文件行开始读取观测值 | 只有一行表头填 2；有表头和单位行填 3 |

#### 多文件导入步骤

1. 选择多文件后，逐文件检查成功或失败状态。默认勾选各文件的第一张表；Excel 可追加其他工作表。
2. 点击对应预览，分别调整表头、单位行和数据起始行。编码与分隔符作用于整批文本文件，修改会重新读取并重置表选择和行设置。
3. 取消导入不会追加数据。确认后数据进入待绘图设置；检查绑定，再生成图形或应用修改。

> 单文件最多 10 MiB；每批最多 50 个文件、合计 100 MiB。损坏或不支持的文件会列出原因，有效表仍可导入。同名文件会分别追加；应用整批后可一步撤销。导入预览只展示部分行，不等于只导入这些行。

### 2.2 数据表管理、列类型与缺失值

1. 点击左侧表名或“数据表预览”，切换“当前数据表”，核对行列数。
2. 修改“表名称”后点击“重命名”；需要重新解释文件行结构时用“调整导入参数”。
3. 点击列头的“设置…列”，修改列名、类型、单位与缺失标记，检查转换结果后点击“应用列设置”。
4. 移除表之前检查引用它的曲线；按删除窗口提供的处理选项操作，再核对诊断。

![图 2.2　列设置：数值类型、单位、缺失标记及转换预览](images/12-column.png)

图 2.2　列设置：数值类型、单位、缺失标记及转换预览

| 列类型 | 用途 |
| --- | --- |
| 数值 number | 曲线 Y、误差、强度 Z、大小/颜色连续映射。 |
| 文本 string | 文字标签、非数值字段。 |
| 分类 category | 柱图类别、分组等离散字段。 |
| 日期 date / 日期时间 datetime | 连续时间 X 轴；配合日历刻度使用。 |

单位是说明性元数据，改变单位文字不会把 m 自动换算成 mm。缺失标记每行一个；可添加常用标记后按本表情况修改。数字中含单位文字、千位符或混用格式时，要看转换失败数量，必要时先整理原始文件。

> 表格预览用于查看和配置数据，并非完整 Excel 单元格编辑器。保留原始数据文件；需批量改数值时，通常在源表中处理后重新导入。工作区最多 1,000,000 单元格，单表处理还受 100,000 行、256 列限制。

### 2.3 曲线绑定、跨表曲线与批量选择 Y

入口：数据绑定。先选数据表，再选当前图型所需角色；自动匹配只是起点，最终以列名和单位核对。展开某条曲线后可修改名称、数据表、列、顺序，或复制、删除该曲线。

| 操作 | 具体用途 |
| --- | --- |
| 新增曲线 | 在当前图层增加一条独立曲线，再设置数据表和 X/Y。 |
| 复制曲线 | 复制现有配置后改 Y 或数据表；检查是否意外绘制同一列。 |
| 上移 / 下移 | 改变曲线顺序与绘制层次；不改变原始数据行。 |
| 跨表绘图 | 不同曲线选择不同数据表。保持坐标含义一致，否则考虑不同轴或图层。 |
| 曲线名称 | 用于图例；修改后应用才更新图形。 |

![图 2.3　批量选择 Y 列：本例只勾选 Sample_A 与 Sample_B](images/03-batch-y.png)

图 2.3　批量选择 Y 列：本例只勾选 Sample_A 与 Sample_B

1. 导入多个数值 Y 列的数据表，点击“批量选择 Y 列”。
2. 选择共用 X，使用搜索、全选 Y 列或清空选择定位目标。X 不列入 Y 候选；误差列和温度列不要误当作主曲线。
3. 点击“添加所选曲线”，再生成图形或应用修改。曲线按原表列顺序添加，同轴相同 X/Y 绑定跳过。
4. 取消窗口不改变绑定；加入后尚未应用，可以“重置待绘图设置”撤回。

批量选 Y 支持折线、散点、柱形（含堆叠）与面积图。复杂图型请按其角色分别设置，不能把所有数值列一律当成 Y。

### 3.1 柱图与统计图：概览及数据要求

#### 柱图与堆叠柱图

1. 导入 [02-category.csv](examples/02-category.csv)，选择柱形图，以 Group 为类别，以 A/B 为数值曲线。
2. 在柱图布局中设置方向、柱间距、重叠比例、基线与堆叠组；堆叠柱形可启用百分比。
3. 在外观中分别设置正负值填充、边框与透明度，在误差和数据标签页绑定并排版。

缺失类别可保留缺口或按零绘制，二者含义不同。分类轴缩放按类别窗口显示；范围 0–3 表示前三个类别，不是类别名字的数值范围。

#### 直方图

1. 导入 [03-distribution.csv](examples/03-distribution.csv)，类型选直方图，样本绑定 Value。
2. 在“分箱”中选择方式：自动、箱数、箱宽或显式边界等界面选项；填箱宽时同步检查起点、终点和边界包含规则。
3. 在统计与分布中选择归一化及统计标注；可叠加 Normal、Lognormal、Weibull、Exponential、Gamma、Laplace、Lorentz、KDE、Poisson、Binomial。参数按各分布定义填写。

> 分布叠加由所填参数或 KDE 设置生成，不能把一条叠加曲线直接当作已完成统计拟合或显著性检验。比较多组直方图时先统一分箱边界与归一化方式。

#### 箱线图

样本绑定 Value，分组绑定 Group；需要双重分组时再设置分裂分组。选择四分位算法、箱体范围、须规则（倍数/百分位等），开启均值、中位数、缺口或置信区间。原始点支持隐藏、确定性抖动、均匀散开；可显示离群与极端值、连接均值/中位数/百分位。报告结果时记录所用统计规则。

#### 面积图

绑定 X/Y，在面积图页设置基线、填充和轮廓；在偏移与填充中配置位置或同轴曲线间填充。需累计时在图层堆叠中选择成员。对交叉曲线、缺失点与非线性轴，应用后检查填充是否符合含义。

#### 宽表矩阵热图

1. 导入 [04-matrix.csv](examples/04-matrix.csv)，将图表类型设为“热力图”，数据绑定中出现“矩阵热图”。
2. 选择 Angle 为坐标列，强度列选 500、550、1000。“Y 数据跨列”使每个强度列成为一行热图；“X 数据跨列”交换布局。

| --- | --- |
| 预设色阶 | Viridis、Plasma、Inferno、Magma、Coolwarm、Blues、YlGnBu、Spectral、Grayscale；可反向或逐项自定义颜色。 |
| 固定范围 | 最小值必须小于最大值；多图比较时用相同范围。 |

| 缺失与间距 | 缺失强度空白；热图支持非等距中心坐标，中点划分单元，也支持单行/单列。 |
| 后续修改 | 图形属性 → 热图曲线 → 颜色映射；调整配色后应用并保存。 |

#### XYZ 与等值线

导入 [05-grid.csv](examples/05-grid.csv)，分别绑定 X、Y、Z，可试热图或等值线。等值线的规则矩阵模式要求完整且等间距的二维网格；散乱点可在数据区域中选择“不规则 XYZ 三角网”，再设置级别、颜色、填充与标签，详见独立教程。

> 矩阵入口最多 99,999 单元；XYZ 热图的 X 唯一值数 × Y 唯一值数最多 100,000，等值线最多 40,000。不能把两列独立光谱强度分别当 Y 坐标与 Z，否则可能产生巨大的稀疏组合网格。

#### 页面与绘图区

图形属性 → 图页 → 打印/尺寸设置页面物理大小；图层 → 大小设置绘图区位置和尺寸。锁定图层宽高比保持形状；“关联轴长与数据比例”约束 X:Y 的数据单位比例，含义与外框长宽比不同。内容适配可辅助整理留白，提交前检查标题与色标。

#### 多纵轴与上下共享 X

1. 先导入所需曲线，图形设置选双、三、四纵轴或上下共享横轴。
2. 为新增曲线分配数据列与相应轴；同一量纲优先共轴，不同量级可分轴。
3. 应用预设后检查页面。三/四纵轴外侧轴默认偏移 60 pt；绘图区不足 60 pt 会提示增大页面。
4. 旧项目直接打开保留旧布局；若外侧轴裁切，可重新应用预设，再手动调整长标题、字号和留白。

> 复制图层会复制配置，仍需检查引用的数据和轴。图层前后顺序影响遮挡；裁剪到图层边框可能截掉超出范围的对象。完整模板可能替换布局，应用前先预览。

### 6.2 数据视图、子集、误差线和数据标签

#### 显示数据与原始数据

在曲线属性的“显示”中设置行范围、无效点连接、X 排序与重复 X 处理。原始表保持不变；“计算与自动范围的数据来源”决定统计与范围依据原始数据还是处理后的所选数据。

| 选项 | 效果 |
| --- | --- |
| 无效点连接 | 跨过无效点连接，或在无效点处断开。 |
| X 排序 | 保留原始顺序、升序或降序；循环扫描数据通常应先保留原序。 |
| 重复 X | 保留全部，或保留原始第一行/最后一行。 |
| 显示抽样 | 不抽样、每隔若干点、按总点数；可保留每段首尾。 |
| 导出也使用抽样数据 | 仅在明确需要时开启；默认导出不因预览抽样而丢弃完整数据，仍保留数据视图和子集限制。 |
| 子集 | 按固定行数或分组列划分曲线内部子集，可断开子集间连线。 |

#### 误差与标签

入口：图形属性 → 选择曲线。XY 曲线的误差字段位于“标签”页下方；柱图使用独立“误差”页。选择 X/Y 或值方向，对称 ± 绑定一列，非对称 −/+ 分别绑定两列；关闭则不绘制该方向。

1. 选择 Sample_A → 标签，向下滚动到误差设置，Y 误差模式选“对称 ±”，误差列选 01-xy.csv 的 Error_A，检查预览是否为各点上下延伸。
2. 高级误差中区分“误差幅值”与“绝对端点”，再选方向、基线、棒或带、连接方式、线色、透明度、抽样与符号避让。
3. 在“标签/数据标签”启用标签，选择来源和格式，调整位置、偏移、字体；密集图先抽样显示标签，避免全部重叠。
4. “垂直线”可将点投影到基线；高级目标可选同轴曲线及插值位置，目标曲线变化后重新检查。

> 误差幅值与绝对端点不可混用。单纯把 Error_A 加为普通 Y 曲线，不会自动得到误差棒。XY 的“标签”页同时容纳标签和误差，窗口较小时需要向下滚动。

### 6.3 曲线组、调色板与连续组色标

1. 图形属性 → 选择图层或 XY/面积曲线 → 组 → 添加曲线组。同组成员需要共用坐标轴。
2. 选择从属模式后，按成员顺序递增颜色、线型、符号；设置同步/嵌套、步长或自定义列表。

| --- | --- |

#### 从数值列名读取参数

选择“从数值列名读取参数”，核对每条曲线的 Y 列名与读取结果，点击“写入 N 个参数”。只接受完整有限数值（可含正负号、小数、科学计数法）；Sample_01、500 K 不会自动提取数字。失败项保留原参数，成功项写入属性草稿，仍需应用。修改列名不会自动更新参数，需重新读取。

组色标复用同一色带、范围和反转；默认关闭。标题未设置时用组名，显式留空可隐藏标题。参数绑定曲线 ID，重排不改变归属；缺失参数保留基础颜色并提示。所有参数相等时取色带中点。多个色标空间不足会阻止应用，需扩大图层或减少色标。

> 曲线组用于统一样式；堆叠子组用于偏移与累积，两者不能混为一谈。同一曲线最多属于一个曲线组，可手动配置父组关系但不能循环嵌套。完整模板保存组配置，仅样式模板保留目标原有组配置。

### 6.4 堆叠、偏移、倍率与子组

入口：图形属性 → 左侧选择图层 → 堆叠。当前版本支持六种模式，选择前先确认成员曲线与坐标轴。

![图 6.3　当前版本堆叠页：无、累积、增量、常量、自动、单独](images/06-stack.png)

图 6.3　当前版本堆叠页：无、累积、增量、常量、自动、单独

| 模式 | 操作与结果 |
| --- | --- |
| 无 | 关闭这一层的堆叠模式，恢复未堆叠显示。 |
| 累积 | 按成员累加；普通曲线要求线性 Y 轴。柱图可排序、百分比归一化、显示总标签。 |
| 增量 | 用于柱/条图的增量浮动展示；可显示被覆盖的柱/条。普通曲线不开放此模式。 |
| 常量 | 输入偏移数列。未勾“绝对偏移”时循环累加；输入 10 得到 0、10、20…；输入 0 10 得到 0、0、10、10、20… |
| 绝对偏移 | 按数列循环赋值，第一条也应用第一项；0 10 得到 0、10、0、10… |
| 自动 | 按数据跨度与间距（默认 8%）错开；提供“保持绘图在非线性刻度下的比例”选项，按当前轴检查预览。 |
| 单独 | 选曲线后设置 X/Y 偏移值与倍率；柱图的类别方向受限，以可用控件为准。 |

1. 对于多组光谱，可先批量选 Y 建立曲线，然后在堆叠页选择“自动”，调整间距。
2. 需要精确位置时切换“单独”，逐曲线检查 X/Y 偏移与倍率；改变模式后核对预览，不假设所有设置完全相同。
3. 需要分组堆叠时设置成员所属子组，再启用“子组内偏移”或“子组间偏移”。
4. 柱图按需启用大小排序、排序方向、百分比、连接线和总标签；可用性由模式与图型决定。
5. 应用后检查坐标范围。固定范围可能截断偏移后的曲线，必要时恢复自动范围。

> 堆叠、偏移和倍率改变显示，不覆盖原表数值。非线性尺度下应检查保持比例选项及定义域；出现不支持提示时改变模式或尺度。“应用于…”中的曲线堆叠会复制相关堆叠配置，提交前核对目标图层。

### 6.5 文字、公式、图例与图形标注

#### 文字与公式

图页的“图例/标题”集中管理曲线图例条目；轴标题在轴属性中设置；独立文字在图页“注释”页添加。文字可调字体、大小、颜色、旋转，以及行对齐、内距、换行、行距、背景和边框。

| 文本模式 | 示例与效果 |
| --- | --- |
| 自动识别 | 裸下划线和 ^ 保留原样；带花括号的 _{...} / ^{...} 表示上下标。 |
| 纯文本 | 列名 Sample_A 需要完全按原样显示时可明确选此模式。 |
| 上下标/富文本类选项 | 按界面提供的模式与语法输入；编辑后看预览，不使用 HTML 标签。 |
| LaTeX 公式 | 自动模式识别 $...$、\(...\) 或以 LaTeX 命令开头的内容；例如 $x^{2}$。用于数学排版，不执行公式计算。 |

#### 添加注释

1. 图形属性 → 图页 → 注释，选择文字、线/箭头、矩形、参考线或跨图层图例，添加对象。
2. 选择页、图层或数据坐标空间，再填写位置、尺寸/端点、文本或样式。数据坐标需要指定所在图层和坐标轴。
3. 跨图层图例选择条目与布局；参考线核对方向与数值，矩形可作为区域强调。
4. 展开预览，确认注释没有挡住数据；应用并保存项目。

#### 直接在画布编辑

双击轴标题或图例文字可原位编辑：单行 Enter 提交，Esc 取消；多行图例 Ctrl+Enter 提交。页/图层坐标的图例与文字可拖动；选中后方向键移动 1 个屏幕 CSS 像素，Shift+方向键移动 10 个。位置按预览比例换算并随项目保存。

> 拖动中按 Esc、切换图层、失去指针捕获或改变窗口大小会取消移动。框选放大模式的拖动用于缩放；有待应用设置或属性窗口时先处理草稿。数据坐标注释通过属性调整。默认图例首次移动后会成为可保存对象并保留当时条目。

### 7.1 坐标轴尺度、范围与重缩放

![图 7.1　坐标轴窗口：先选下/上 X 或左/右 Y，再编辑刻度与范围](images/08-axis.png)

图 7.1　坐标轴窗口：先选下/上 X 或左/右 Y，再编辑刻度与范围

1. 预览工具栏 → 坐标轴 → X 轴或 Y 轴；左侧再选需要修改的具体轴。
2. 在“刻度”页选择尺度，设置最小/最大值与重缩放策略；查看右侧预览。
3. 需要回到数据范围时点击“恢复…自动范围”，或使用“按当前策略重缩放”。
4. 在标题页检查自动列名或手动文字，应用后回到主图。

| 尺度 | 数据要求与用途 |
| --- | --- |
| 线性 | 一般数值；相同数值差对应相同距离。 |
| Log10 / Ln / Log2 | 普通对数要求正值；对跨数量级数据有用。可选对数细分策略，Log10 另有窄区间兼容策略。 |
| SymLog | 先选对数尺度，再勾“对称对数”，设线性范围阈值和线性段长度；用于跨零数据。 |
| Probability / Probit / Logit | 界面使用百分数，数据须处于其有效域；避免 0、100 等变换奇点。 |
| Weibull | 界面使用比例，核对有效域；不要与百分数混用。 |
| 倒数 / 偏移倒数 | 避免分母为零；偏移倒数可设置偏移常数。 |
| Discrete 数值 X | 按离散数值位置处理，不等同于分类字符串轴。 |
| 自定义公式 | 填写正向、反向公式与定义域，须在整个域内单调且互相还原。 |

#### 自动范围与固定范围

Auto 在相关数据变化后适配范围；Fixed 保持当前范围；Normal 和固定一端的组合用于有条件重缩放。两端边距 0–100% 在下一次重缩放时生效，固定端不加边距。换表、堆叠、批绘后范围异常，先检查是否固定。

自定义尺度支持 x、四则运算、^、sqrt、ln、log10、log2、exp、abs。示例正向 `x/1000`、反向 `x*1000` 必须配合有效定义域。仅改变数字显示时用“刻度标签公式”，不要为换标签而改变坐标尺度。

> 刻度标签公式 x/1000 只改变显示文字，原始数值和刻度位置不变。单位转换、尺度变换、标签格式是三件不同的事。

| --- | --- |
| 复制 / 粘贴格式 | 当前工作期间快速统一外观。 |
| 应用于… | 把刚调好的某一类属性分发到其他对象，例如线条、字体、堆叠。 |
| 多选编辑 | 同时设置多个选中对象支持的属性。 |
| 仅样式模板 | 跨项目或长期复用一套样式。 |
| 完整模板 | 复用数据槽、图层、坐标轴和图形结构。 |

> 格式复用不等于更换数据。不同对象支持的字段不同，禁用字段不能强行应用；修改后检查目标轴范围、图层位置与组配置是否仍符合预期。

### 8.2 模板保存、JSON 迁移与 Origin 原生导入

![图 8.1　模板中心：当前初始模板库为空，可先保存自己的图形或导入模板](images/09-templates.png)

图 8.1　模板中心：当前初始模板库为空，可先保存自己的图形或导入模板

#### 创建与管理个人模板

1. 先完成并应用一张有效图形，打开模板中心。填写模板名称与逗号分隔标签，点击“保存预览为我的模板”。
2. 选择已有模板，可搜索、重命名、删除或导出 JSON。跨设备之前先导出备份。
3. 导入模板 JSON 后，选择仅样式或完整模板；配置完整模板的数据槽，生成模板预览。
4. 检查预览后点击“应用预览并关闭”；取消放弃未应用内容。

| 套用范围 | 结果 |
| --- | --- |
| 仅样式 | 复用样式，尽量保留目标结构与数据；组配置保留目标原有设置。 |
| 完整模板 | 复用模板结构和格式；必需数据槽必须映射到有效列，逐层检查。 |

模板保存在当前站点的浏览器 IndexedDB；清理站点数据会丢失。模板用于复用样式/结构；完整工作数据用 .plotfig.json 保存。当前没有预置期刊模板列表，不能依赖旧手册中的预设。

#### Origin OTP / OTPU

1. 在本机 Windows 上通过 Vite dev 或 Vite preview 运行编辑器，确保已安装并可正常启动 Origin。
2. 模板中心 → 我的模板 → Origin 原生模板，必要时先“检测 Origin 导入服务”，选择 .otp/.otpu（最多 16 MiB）。
3. 等待独立 Origin 会话转换；支持取消。查看示例图与兼容提示。
4. 点击“保存导入模板”，新模板自动选中，再按仅样式或完整模板映射自己的数据。保存模板本身不替换当前图形。

> 原生转换只在本机处理，静态网页没有本机转换接口。映射范围包括可支持的折线、散点、线加符号、柱条、面积与部分堆叠；复杂分组、特殊字体/标注可能有差异。含可执行脚本、自定义表达式或需求值标签的模板会拒绝导入，不能承诺无损复刻。

### 8.3 按数据表批量绘图与输出项目

![图 8.2　数据表批绘：左侧数据、格式与输出设置，右侧逐项预览](images/10-batch.png)

图 8.2　数据表批绘：左侧数据、格式与输出设置，右侧逐项预览

1. 导入结构相似的多张数据表，先完成一张代表图，并应用或重置所有待绘图设置。
2. 预览工具栏“模板”分组 → 数据表批绘，勾选数据表。默认绘图依据是“当前已应用图形（直接批绘）”，无需先保存模板。
3. 设置复用格式；展开手动映射检查 X/Y 等必需角色。预览项目下拉框及上一项/下一项可逐表检查。
4. 选择 SVG、PNG；在更多输出中按需要包含可重新打开的项目。
5. 开始批处理；完成后下载已完成文件 ZIP。失败或取消项可重试，成功文件保留。

| 选项 | 行为 |
| --- | --- |
| 自动识别两列 XY | 优先手动映射、同名列，再识别 X/Y 表头，仍不匹配时用第一列 X、第二列 Y；X 可为数值/日期/日期时间，Y 必须为数值。 |
| 多曲线换两列表 | 单图层同轴多条 XY 无法完整匹配时，可保留第一条及其样式，避免重复绘制同一 Y。关闭自动识别可恢复严格匹配。 |
| 复用格式 | 沿用当前图形格式、所有样式格式、所有格式、自定义格式。 |
| 自定义格式 | 可选页面背景、已有图层图例格式、图层背景、图层尺寸、刻度与范围、颜色、字体；未选项保留目标设置。 |
| 刻度与范围 | 选中或使用所有格式时复用源范围；否则换表按重缩放策略适配。固定范围可能截断新表数据。 |
| 完整模板 | 必须配置必需槽；原图依赖多张表时，按表批次也要逐项确认所有映射。 |

批绘不会修改当前工作区。图层按顺序对应，来源不足时循环复用；复用尺寸保留目标位置，复用范围保留目标轴标题。自动标题随新列名更新，手动标题保持。预览、图片与项目使用相同格式选择，修改配置后旧结果清空，需要重新运行。

> 每批最多 50 项，输入不超过 100 MiB，输出不超过 200 MiB；ZIP 内含序号、安全文件名与 manifest.json。批次状态不跨会话保存。复杂图型、重复列名、多列或类型错误需显式映射。每项绑定一张表不代表能自动解决原图所有跨表依赖。

### 8.4 一张表的多个 Y 列

目标：一张图中叠加多个 Y；输出是一张多曲线图。练习数据为 [07-multi-axis.csv](examples/07-multi-axis.csv)。

1. 导入数据，图型保持折线图，共用 X 选 X。
2. 打开批量选择 Y 列，清空选择后仅勾 A、B、C、D，添加所选曲线。
3. 生成图形；如果量级差异太大，使用独立多轴、分层，或明确需要的归一化处理。
4. 多组光谱需要错开时，图层属性 → 堆叠 → 自动，设置间距，再到组页递增颜色。
5. 同一数据列无需重复添加；已有同轴 X/Y 绑定会跳过。修改仍在待绘图阶段时可以整体重置。

| 期望 | 检查 |
| --- | --- |
| 曲线数 | 4 条；原始数据表不变。 |
| 名称和顺序 | A、B、C、D 按原表列顺序。 |
| 输出 | 保存一个项目，导出一张图。 |

> 批量选 Y 不会自动为每个 Y 导出单独文件。需要逐张结果时，把数据组织为多表批绘，或建立多个图层再逐层导出。

### 8.5 多个文件自动生成独立图形

目标：让两个同结构文件复用同一绘图格式，分别输出。可以从零导入 01-xy.csv 与 06-xy-repeat.csv；也可打开 [批绘练习起点](examples/projects/batch-start.plotfig.json)，其中另附一张异名列数据表供下一节练习。

1. 多选导入 01-xy.csv 和 06-xy-repeat.csv，预览中各选第一张表，确认导入。
2. 先在第一张表上做好 Time_s / Sample_A、Time_s / Sample_B 两条曲线，应用修改。
3. 点击数据表批绘，只勾选这两张表；绘图依据保持“当前已应用图形（直接批绘）”。
4. 复用格式选沿用当前图形格式；自动识别两列 XY 保持开启，同名列优先匹配，因此本例仍保留两条曲线。
5. 切换预览项目，确认第一项终点 3.1/2.7，第二项终点 5.3/3.3。

7. 开始批处理，等待两项成功，再下载 ZIP。每项应有 SVG、PNG、plotfig.json，另有 manifest.json。

> 左侧是独立滚动区；手动映射、更多输出和批次明细位于折叠区，窗口较小时需在该区域内向下滚动。批处理期间配置被锁定。

### 8.7 模板与格式范围

1. 先保存一个有代表性的个人模板，或导入模板 JSON。打开数据表批绘，在绘图依据中选择它。
2. 只统一外观选仅样式；连图层/坐标轴结构一起复用选完整模板，并完成所有必需数据槽。
3. 不选模板也能直接选所有样式格式、所有格式或自定义格式。
4. 自定义只勾颜色、字体时，目标轴范围和尺寸保持；勾刻度与范围时，批次会采用来源范围。
5. 修改格式选择后重新运行，旧输出清空；不要把修改前 ZIP 与修改后预览混用。

| 复用项 | 练习方式 / 预期 |
| --- | --- |
| 所有样式格式 | 两张数据范围不同的表统一样式，允许各自自动范围。 |
| 所有格式 | 连尺寸与范围一起复用；第二张表可能有点被裁切，必须检查。 |
| 自定义：颜色、字体 | 只统一这两项，不强制轴范围。 |
| 自定义：图层尺寸 | 复制宽高，保留目标位置。 |
| 图例格式 | 复用已有图层图例的排版，曲线名称来自目标数据/设置。 |
| 完整模板 | 保持完整结构、组设置与数据槽，适合固定结构的系列报告。 |

> “同样式”和“同坐标范围”是不同需求。要做跨样品直接比较可固定范围；只要求风格一致时不要误选会裁剪数据的固定范围。

### 8.9 一个图页的多个图层分别导出

目标：将当前项目的图层分别输出。可用 [共享横轴示例](examples/projects/stacked-shared-x.plotfig.json)理解图页结构；独立图层适合直接单独导出，联动图层要核对隔离后的含义。

1. 用图层管理创建或复制图层，分别绑定数据；检查各层均有有效图形并应用。
2. 导出图形 → 批量导出图层，勾选要导出的图层。
3. 选择 PNG 或 SVG、文件名、DPI、透明背景；PNG 可取消自动像素后统一宽高。
4. 选中图层预览，确认单层轴、图例与附加对象完整，再执行导出。
5. 下载 ZIP 并检查状态。相互依赖的多轴图要保留完整关系时，应导出当前整张图形。

| 批量入口 | 处理对象 | 结果 |
| --- | --- | --- |
| 批量选择 Y 列 | 同一表的多个 Y | 同图多条曲线 |

| 数据批量导入 | 多个文件/工作表 | 多张待绑定数据表，本身不等于完成绘图 |

### 8.10 SVG、PNG 与逐图层批量导出

![图 8.6　当前导出窗口：PNG/SVG、DPI、自动或手动像素尺寸和输出预览](images/11-export.png)

图 8.6　当前导出窗口：PNG/SVG、DPI、自动或手动像素尺寸和输出预览

1. 确认图形已应用，点击“导出图形”。选择“当前图形”或“批量导出图层”。
2. 选择图像类型与文件名；透明页面背景只清除页面背景，图层自身背景仍保留。
3. PNG 输入 DPI，默认自动根据页面物理尺寸计算像素。需要严格尺寸时取消“自动计算像素尺寸”，输入宽高，例如 1600 × 1000。
4. 点击“预览”，查看内容比例和留白。满意后导出；逐层模式先勾选图层，运行后下载 ZIP 并检查每项结果。

| 格式 / 设置 | 用途与限制 |
| --- | --- |
| SVG | 矢量输出，保留页面物理尺寸，适合缩放与进一步排版。依赖目标软件字体与 SVG 支持。 |
| PNG | 位图输出；DPI 为 72–2400 的整数，常用选项 96、150、300、600、1200。 |
| 自动像素 | 像素宽 ≈ 页面宽 mm ÷ 25.4 × DPI，高度同理。 |
| 手动像素 | 每边 1–8192，最多 32,000,000 像素；不同长宽比通过扩展留白保持内容比例。 |
| 批量导出图层 | 将当前图形各选中图层分别输出；使用本窗口当前设置。与按数据表换数据批绘不同。 |

例如页面宽 180 mm、300 DPI，输出宽约 2126 px。相同 DPI 只有在页面物理尺寸也相同时才意味着相同像素尺寸。多张图严格对齐还需要相同字体、轴范围与绘图区边距。

> 当前应用直接提供 SVG、PNG 和 ZIP，不提供原生 PDF/EPS 导出入口。浏览器打印本手册为 PDF 与应用导出科研图形是不同功能。保存图片不会保存可继续编辑的工作区。

### 9.1 项目文件、自动恢复与跨设备备份

1. 生成/应用图形，确认属性草稿已提交。点击页面顶部“保存项目”，下载 .plotfig.json。

3. 关闭或换项目前保存最新文件；图像、模板、项目分别通过各自入口处理。

| 文件或存储 | 保存内容与用途 |
| --- | --- |
| .plotfig.json | 图形模板、工作区数据与绑定；跨设备继续编辑的主要文件。 |

| SVG / PNG | 排版交付用图像，不替代工作区项目。 |
| 恢复草稿 | 此浏览器此站点中的已应用工作区副本，不跨设备同步。 |
| 原始 CSV / XLSX | 数据来源，留作修正、核查与重新导入。 |

![图 9.1　恢复窗口：选择已有副本恢复、删除，或本次跳过](images/14-recovery.png)

图 9.1　恢复窗口：选择已有副本恢复、删除，或本次跳过

#### 自动保留恢复草稿

默认开启。生成或应用后停止编辑约 2 秒自动保留，持续修改时约每 30 秒内发起一次保存尝试，后台页面可能被浏览器延迟。未应用绘图设置、属性输入及撤销历史不写入草稿。

刷新或重开后在恢复窗口选择副本，也可本次跳过。恢复会清空撤销历史，仍保留未下载提醒；手动下载不会删除恢复副本。同站点最多 3 份，每份不超过 20 MiB，总载荷不超过 60 MiB；满额需逐条清理，不自动淘汰旧副本。

> 关闭自动保留会同步到同站点其他标签页，已有副本仍可恢复或删除。删除当前副本后，需要“重新保留当前工作区”才再次创建。清理浏览器站点数据会移除模板和草稿；存储失败时仍可手动保存与导出。

### 9.2 常见任务配方与排错

| 任务 | 最短操作路径 |
| --- | --- |
| 多组 XRD 错开显示 | 导入宽表 → 批量选 Y → 生成 → 图层堆叠选自动 → 调间距 → 组配色 → 保存。 |
| 温度作为整条曲线颜色 | 每个温度一条曲线 → 建从属组 → 数值映射 → 输入温度或从纯数值列名读取 → 显示组色标。 |
| 二维温度强度图 | 导入 04-matrix.csv 类宽表 → 热力图 → 矩阵入口 → 数值列名作为跨列坐标 → 选强度列 → 生成。 |
| 多个文件同样式出图 | 批量导入 → 做好代表图 → 应用 → 数据表批绘 → 检查映射与范围 → ZIP。 |
| 相同像素的报告插图 | 各图导出取消自动像素 → 相同宽高 → 预览 → PNG。再统一绘图区与字体。 |
| 两个量级共同 X | 双纵轴预设 → 分配曲线与 Y 轴 → 设置两边标题/范围 → 检查页面留白。 |
| 继续昨天的工作 | 打开 .plotfig.json；没有手动下载文件时检查同浏览器、同站点的恢复草稿。 |

| 现象 | 优先检查 |
| --- | --- |
| 有数据但没图 | 必需角色有无绑定、列类型是否有效、是否点击生成/应用、诊断是否报错。 |
| 改了属性主图不变 | 当前编辑的是哪个对象，是否仅修改草稿，是否点击应用或确定。 |
| 保存或批绘不可用 | 是否存在待绘图设置、无有效图形、正在执行任务或映射未完成。 |
| 乱码或一整列 | 编码、分隔符；改变批次导入设置后重新勾表和设置行号。 |
| 曲线缺点/错序 | 缺失标记、转换失败、X 排序、重复 X 处理、行范围、子集与抽样。 |
| 曲线或轴文字裁切 | 固定范围、堆叠后偏移、图层裁剪、页面尺寸、多轴预留、色标空间。 |
| Log 或公式报错 | 零负值、奇点、定义域，正逆函数是否单调且互逆。 |
| 模板中心为空 | 当前版本没有内置模板；保存自己的图或导入 JSON/OTP。检查站点是否改变。 |
| 恢复副本不出现 | 浏览器/用户配置/站点端口是否相同、是否关闭保存、配额是否已满；优先打开手动项目文件。 |
| 热图报超限 | X×Y 唯一值组合是否过大；宽表应使用矩阵入口，不把强度当 Y 坐标。 |
| 批绘部分失败 | 查看逐项预检与 manifest；检查必需槽、重复列名、数值类型、范围和输出限额。 |
| 透明导出仍有底色 | 页面透明不移除图层背景；在图层属性中检查背景。 |
| 快捷键无效 | 焦点是否在输入框，是否有弹窗或待应用设置；先提交/取消草稿。 |
| Origin 导入失败 | 本机 Windows、Origin 可启动、同源回环 Vite 服务、16 MiB 文件上限及兼容/拒绝提示。 |

#### 交付前检查

核对数据和单位、图型和曲线数量、误差含义、坐标范围、色标范围、图例对应、文字裁切与输出宽高。保存 .plotfig.json、导出图像，并保留原始数据；批处理检查失败项，而不只看 ZIP 是否下载成功。

#### 建议完整练习路线

1. 用 01-xy.csv 完成折线、散点、线加符号；给曲线加误差和标签。
2. 用 02-category.csv 完成分组、横向、堆叠和百分比柱图；用 03-distribution.csv 完成直方图和箱线图。
3. 用 05-grid.csv 完成 XYZ 热图及两种等值线；用 04-matrix.csv 完成矩阵热图。
4. 用 07-multi-axis.csv 完成双/三/四纵轴及上下共享 X；对照示例项目。
5. 打开 batch-start.plotfig.json，完成异名映射、三表批绘和逐层导出。
6. 保存项目、关闭后重开，对照图形与数据；下载图片并检查尺寸、字体、单位和裁切。
