# Origin 2026b 默认样式适配

目标：将 Web 新建 XY 图形改为依据 Origin 2026b 公开资料的现代科研图样式。用户已授权直接实施，不要求再次验收。

依据：Origin 官网确认 2026b 于 2026-06 发布；Graph Options / FAQ-1219 说明 2025b 起默认采用更宽图页、更小留白、完整图层轴框和新的文字/轴线格式。官方未公开完整 2026b 出厂模板数值，因此以下尺寸与字号是 SZ-Plot 的明确适配选择，而非声称逐项复刻。

- https://www.originlab.com/whatsnew
- https://docs.originlab.com/quick-help/why-graph-looks-different-in-2025b/
- https://docs.originlab.com/origin-help/graph-options-set-graph-default/

适配值：白底、黑色 Arial 10 pt 刻度、12 pt 轴标题，深灰 #515151 实线 1.5 pt、实心方形符号 5 pt；180×120 mm 横向图页；上/右边框无刻度与重复标签；单曲线默认隐藏图例。图层为页面 x=16%、y=6%、宽=81%、高=79%，外侧保留文字空间。延续当前点线图模式，初始轴标题为 X/Y，可在属性弹窗编辑。

风险与边界：不改变 schema、数据绑定或项目文件结构；恢复项目继续使用所存模板。渲染坐标改为物理 pt，会修正所有图形此前偏小的文字/线宽以及固定比例问题；PNG 以 1000px 宽为 1×，高度随图页比例计算。自动标签避让、刻度向内、自动列元数据标题不在本次默认模板适配范围。
