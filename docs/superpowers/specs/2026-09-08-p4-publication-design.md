## 方案选择

| 方案 | 收益 | 代价 |
| --- | --- | --- |
| A：浏览器编辑 + 本机 Inkscape 导出模块（推荐） | 共用现有 SVG，使用成熟引擎输出 PDF/EPS；可验证字体、裁剪与物理尺寸 | 增加独立本地服务和外部引擎；需要明确扩展旧 Web 的无本地进程约束 |
| B：全部在浏览器完成 | 维持静态部署；PDF 可使用 jsPDF/svg2pdf.js | EPS 需另写受限转换器或引入 WASM；字体嵌入、透明度及解释器验证工作较大 |
| C：扩充远端导出服务 | 部署统一引擎，用户无需安装 | 引入上传、服务部署、访问控制与运维，超出现有本地工作方式 |

推荐 A。编辑、绑定、SVG/PNG 和批量编排仍在浏览器；PDF/EPS 请求只发送当前生成的 SVG 到本机回环地址。浏览器独立运行时明确显示 PDF/EPS 引擎未连接，不能把该状态计作四格式验收完成。

Inkscape 官方记录命令行可输出 SVG、PNG、PS、EPS 和 PDF；这仅证明格式能力，不代表本项目字体、裁剪和透明度已验收。[官方说明](https://wiki.inkscape.org/wiki/Using_the_Command_Line)

方案 B 的候选版本通过 `pnpm view` 核验：`jspdf@4.2.1`、`svg2pdf.js@2.8.1`、`svgpath@2.6.0`、`opentype.js@2.0.0`。svg2pdf.js 的 peer 范围接受 jsPDF 4，官方要求额外注册非基本字符字体，并注明不能用 JSDOM 完成转换验收。本设计选择 A，不安装这四项。[svg2pdf.js 文档](https://github.com/yWorks/svg2pdf.js/)

## 一、共享协议与项目兼容

FigureTemplate/FigureDocument 从 1.1.0 升为 1.2.0，同步 TypeBox、公开类型、JSON Schema、域校验、迁移和全部消费方。项目外壳继续为 2.0.0；旧 1.0.0 外壳及 0.1.0/1.0.0/1.1.0 内嵌模板继续经已有迁移链加载。

- 增加可选 `sharedAxisGroups`：每组含稳定 ID 和 `{panelId, axisId}` 成员引用，一个轴最多属于一个组。组内 dimension、scale、reverse 和 range 必须一致；标题、显示位置、字号及刻度标签可独立。
- 注释增加可选可见性、文本样式、线/填充样式、旋转与箭头样式；图例增加布局、锚点、列数、条目顺序、字体、样例尺寸、间距、背景和边框。缺省样式确定且可迁移复现。
- 保留 XY 误差字段。普通 grouped Bar 新增沿值轴的对称/非对称误差角色 `valueError/valueErrorLower/valueErrorUpper`，不因横竖方向切换而交换列绑定。
- 新字段采用封闭结构；不把 P4 的核心字段塞入不校验的 extensions。当前 Origin 导入仍产生既有 XY 内容，通过版本适配保持兼容。
- 旧自动系列图例迁移为等效 Panel 图例配置；已有注释图例改为真实图例，避免与旧自动图例重复绘制。对旧固定图例溢出的修正属于预期变化。
- 迁移不得修改原始表、重新生成已有稳定 ID 或重排系列；失败保留当前工作区。

## 二、图例、注释与误差棒 UI

保留现有“对象树—属性草稿—应用”的交互方式，扩展为图页、Panel、轴、图表、图例和注释。未应用草稿不得进入导出；无效参数保留草稿并定位错误。

**图例：** 支持 Panel 图例和全图图例；显示/隐藏、位置锚点与坐标、横排/竖排、多列、条目选择/排序/名称、字体、样例尺寸、行列距、边框与背景。样例复用真实线型、符号、柱/箱体样式；Heatmap/Contour 的颜色条继续单独管理。自动图例收集有效且可见的系列；全图图例按 Panel、系列顺序收集，不按相同文字擅自合并。提供图内和预留页边距位置，越界或放不下有诊断。

**注释：** 可新增、复制、删除和重排文本、箭头、矩形、横/纵参考线。属性包括归属、坐标空间、位置或起止点、可见性和适用样式。页面/Panel 坐标沿用左下角原点的 0–1 比例坐标；数据坐标明确选择 X/Y 轴，跟随固定范围、对数和反向轴。坐标空间转换须保持屏幕位置，无法反解时提示并保留旧值。分类轴首期不提供任意数值的数据坐标注释，仍可使用 Panel 坐标。

箭头必须有箭头头部；矩形有实际描边/填充；参考线有明确方向及数值。页面注释放在 Panel 绘制后，数据注释遵循裁剪，页内注释不被图层背景意外盖住。首期以属性表单和键盘操作完成精确编辑，不要求自由手绘。文本支持 Unicode；旧 `format=latex` 原文保留且明确显示“按源码显示”，本轮不新增 TeX 排版引擎，不把原文显示宣传成公式排版。

**误差棒：** XY 分别设置 X/Y 的关闭、对称、非对称模式及列绑定；grouped Bar 支持值轴误差。可改颜色、线宽、端帽宽度和显示状态。误差值是非负距离；非对称必须成对，对称/非对称互斥；同系列按行对应的数据必须来自同一表。缺失或负误差只跳过相应误差棒并标出来源，中心点继续显示。自动范围包含合法误差端点，对数轴遇到非正端点给出诊断，不能产生无效坐标。

不自动计算 SD/SEM/CI。Stacked Bar、Histogram、Box 的统计误差定义不在本轮；对应控件解释适用图表，不能提供无效果的开关。

## 三、多 Panel 与共享坐标轴

- 支持新增、复制、删除和排序 Panel；最后一个 Panel 不可删除。网格布局提供行列、外边距、横纵间距及 a/b/c 标签，也可数值编辑各 Panel 的 frame。
- 复制 Panel 为其内部对象分配新 ID，重写轴、系列、数据槽和注释引用；源列引用可以复用，后续修改绑定相互独立。共享轴组默认不随副本自动加入。
- 删除前显示将移除的图表/注释；只清理失去所有引用的槽位与绑定，不删除原始表。共享组余下不足两轴时移除该组。该产品交互确认与本次代理文件操作权限分开。
- 数据绑定、类型切换、系列操作及属性应用均作用于选中的 Panel；页面尺寸与主题继续是全图属性。需要消除“首 Panel”假设，不能只增加切换器。
- 共享 X、共享 Y 支持全图、同行、同列以及手工组。新建组先检查轴兼容性；不同固定范围、scale 或 reverse 不静默覆盖，由 UI 展示统一设置再应用。
- Renderer 先准备全部有效图表及误差/统计派生范围，再按共享组求联合轴域，最后为各 Panel 建立映射。同组采用同一数据范围，但保留各 Panel 的实际屏幕矩形。
- 分类共享轴按 Panel/系列/原始类别首次出现次序求稳定并集，保留数字和文本类别的区别。数值、对数、分类不能混组；堆叠、分箱、误差端点等均进入联合范围。
- 固定范围按组统一应用；反向也统一。隐藏内部刻度标签只影响显示。解除共享后保留该轴显式设置，auto 则恢复单 Panel 自动求域。

## 四、模板库、主题与期刊预设

模板库包含内置模板与“我的模板”，支持预览、搜索、标签、另存、重命名、删除以及 JSON 导入/导出。内置集合包含单图、上下双 Panel、左右双 Panel、2×2 共享轴、柱/统计图和网格图；图表类型仍遵循 P3 的绑定契约。

“我的模板”使用独立版本 1.0.0 的 IndexedDB 存储，仅保存图形模板、元数据和缩略图，不保存原始数据表。存储失败显示原因；仍可导出模板 JSON。删除仅由用户在库中操作触发，不影响已经应用的项目。加载模板必须先经迁移与校验，禁止执行模板携带的脚本。

区分两种应用方式：

1. **套用样式**：更新页面、字体、线宽、符号、配色、图例样式；保留 Panel/系列 ID、绑定、图表类型、原始数据、标题内容与数值范围。显式更新现有对象样式，避免只改 theme 却不改变图形。主题包含简洁学术、黑白印刷及已有可访问配色。
2. **套用完整模板**：使用目标模板布局和图表槽位，先展示“模板槽位 → 当前数据表/列”的映射；预览验证成功后整体应用。名称歧义、缺列或类型不兼容必须由映射页解决，不能按列下标猜测。

期刊预设初始包含通用单/双栏、Nature 最终图和 IEEE 单/双栏。每项保存来源 URL、核对日期、物理宽度、建议高度/字体/线宽/格式/DPI，以及检测规则；应用后展开为项目中的实际值，后续预设更新不改变旧项目。

- Nature 最终图优先按其最终图指南设置，避免混用初稿指南；字体大小规则、Panel 标签和可编辑文字要求单独检查。文字转曲不能被视为符合该预设的默认输出。[Nature 图形规范](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)
- IEEE 官方列出单栏 3.5 in、双栏 7.16 in，以及彩色/灰度和黑白线稿的不同分辨率要求；预设以英寸为准确来源，毫米是显示换算。[IEEE 尺寸与分辨率](https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/create-graphics-for-your-article/resolution-and-size/)
- 用户可修改预设值；导出前列出超出预设的项目，不宣称预设等于期刊录用或全面格式合规。

## 五、四格式导出与本机模块

单图和批量共用 `模板 + 绑定数据 → SVG 快照 → 格式编码`。点击导出时冻结已应用状态，异步完成期间的编辑不改变该次输出。

| 格式 | 约定 |
| --- | --- |
| SVG | 保留矢量对象、真实物理宽高、pt viewBox、文本和裁剪；自包含，不引用远端资源。 |
| PNG | `像素 = round(物理英寸 × DPI)`；150/300/600/1200 DPI 与自定义值，显示实际像素。写入与 DPI 一致的 pHYs 元数据，提供背景设置；超出边长/总像素上限拒绝且说明，不静默降采样。 |
| PDF | 以物理尺寸建立页面，保留矢量线、字、裁剪和透明度；默认保留可编辑文本并核查字体嵌入。文字转曲是显式选项，Nature 预设提示不符合可编辑文字要求。 |
| EPS | 有效 EPSF 标头、BoundingBox/HiResBoundingBox 和真实物理尺寸；不透明图形保留矢量，文字嵌入/转曲行为须实际检查。透明度不能默默改为不透明，提供“拒绝有透明内容”或明确的高分辨率扁平化选项，并在结果中标注栅格化。 |

导出预检包含尺寸、字体缺失、透明度、越界对象和渲染诊断。旧项目中的系统字体必须能在浏览器和本机引擎解析；缺失时提示选择替代字体，并先重新预览，不能在导出时无提示替换。随项目引入可再分发的基础字体资源时须保留其许可和来源；不复制系统商业字体到仓库。

新增独立 `packages/export-service`，使用 Node 内置 HTTP 与参数数组调用 Inkscape，不把本地进程能力引入 figure-schema/data-binding/svg-renderer 或浏览器包。提供能力查询及 PDF/EPS 编码；只监听回环地址，限定编辑器 Origin，使用启动时令牌；输入按资源上限和 SVG 白名单校验，禁止脚本、外部资源、DTD、任意路径或命令参数。

每次导出有独立临时目录、超时、输出大小上限与清理；并发上限 2，只取消本次创建的进程。接口返回文件内容和诊断，浏览器负责下载。启动说明明确区分浏览器编辑器和本机模块，未检测到引擎时返回可理解的能力状态。

推荐新增依赖候选：浏览器 ZIP 使用 `fflate@0.8.3`（MIT），服务 SVG 解析使用 `saxes@6.0.0`（ISC）；以上版本与许可已通过 `pnpm view` 核查。Node 继续使用当前 24.13.0；外部引擎采用实施时核验的 Inkscape 稳定 Windows 版本，验收记录实际版本。Ghostscript 作为 EPS 独立验证工具，Poppler 作为 PDF 检查工具。

本机当前 PATH 和常见安装路径未检测到 Inkscape；PATH 未发现 Ghostscript；已有 Poppler 的 pdftoppm。安装/配置这些工具属于本次待确认环境变更。本设计尚未安装任何依赖或工具。

## 六、批量套用与批量导出

批量任务有两种明确入口：多个已保存项目，或同结构的多张工作区数据表。每个项目作为独立 Figure；多表模式使用同一模板及事先确认的角色/列名映射，每张表生成一图，不把多表隐式拼接。

- 显示任务清单、模板模式、格式多选、尺寸/DPI、命名规则和目标预览；默认命名为来源名 + 模板名 + 格式，重名稳定加序号。
- 批量套用在每项副本上执行；保留当前编辑项目。支持导出套用后的项目文件，方便后续编辑与复现。
- 执行前逐项校验映射，状态为待处理/运行/成功/失败/已取消。单项失败不阻断其他项；允许重试失败项和取消后续任务。
- 使用同一单图导出函数；默认顺序处理大 PNG、最多两项矢量编码，导出后释放临时对象和 URL。
- 输出单个 ZIP，包含成功文件和清单 JSON（来源、模板版本、预设快照、输出参数、警告、失败原因）。全失败时仍允许下载报告，界面不得显示成功。
- 首期上限建议 50 项；单项目沿用现有 20 MiB，输入合计 100 MiB、累计输出 200 MiB。编码前后检查配额，超限停止新增项并保留已完成结果；不能无限缓存 Blob。
