## 审查与修复

已完成按协议、绑定、渲染、UI 与保存链路的本地审查。用户限定的子代理模型当前不可用，因此未声称进行独立子代理评审。新图表核心函数检查涵盖长度、位置参数、文件长度及分支复杂度；保留原有 P0–P2 的无关代码。

## 明确边界

- Heatmap / Contour 首期仅接受同表、等间距的 XYZ 网格，各维至少两个坐标；网格最多 40,000 个位置。Contour 要求完整有限数据，最多 50 层且位置数 × 层数不超过 2,000,000。
- Bar 不隐式聚合重复类别；Area 每段 X 严格单调。Box 使用 Type 7 分位数和 1.5 × IQR 内的实际样本须。
- Web 仍编辑单 Panel；多系列切换若与共享轴不兼容，会提示并保留原图。Origin 导入仍只支持既有 XY。
- Pie、Polar、百分比堆叠、Stacked Area、散点网格插值及矩阵编辑未纳入本轮。
- 未提交、推送或执行其他 Git 历史/远程操作；现有 P0–P2 未提交改动已保留。
