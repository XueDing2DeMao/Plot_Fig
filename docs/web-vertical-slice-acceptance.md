# Web XY 垂直切片验收记录

## 目标

验证本地 CSV 经 `DataBindingSet` 绑定到 `FigureTemplate` 的 `DataSlot`，再由纯函数 SVG renderer 输出确定性的 XY 图形，并在 React Web Editor 中预览。`PlotSlot` 只描述图形语义，`DataSlot` 只描述数据角色；二者不合并。

## 支持范围

- 本地 CSV、TXT/TSV、XLSX、剪贴板；文本支持 UTF-8、GB18030、UTF-16、逗号/Tab/分号/空格分隔，导入先预览并确认。
- 数据工作区支持多表、表头/单位行/数据起始行、表重命名与移除；新导入的列默认按 `number` 处理，原始值保留并可重新整理。表格和绑定选项仅显示列名与单位，列设置仍可调整文本、分类、日期与日期时间。
- 每条曲线选择数据表与 X/Y 列；选择“自动匹配”在所选表内匹配。日期 X 投影为 UTC 毫秒，日期刻度格式尚未提供。
- 单个 Panel 支持多条 XY 曲线；可新增、复制、删除、上下排序，并为每条曲线独立绑定 X/Y 数据列。
- XY 三种 plot mode：`markers`、`line`、`line-markers`，界面标签分别为“散点”“折线”“折线 + 标记”。
- 线、点、图例、坐标轴、刻度/标签/标题、对数尺度、对称/非对称误差棒，以及文本、箭头、矩形与 reference-line annotation 的确定性 SVG 输出。
- `.plotfig.json` 2.0.0 本地项目保存 FigureTemplate、全部表的原始数据、列设置和绑定，也允许保存未完成的整理状态；旧版 1.0.0 项目可迁移打开。
- 项目文件执行 `kind`、版本、模板、工作区结构和引用校验；上限 20 MiB。打开失败时显示诊断并保留当前工作区。
- 数据只在浏览器内存中处理，用户可主动下载项目文件；没有上传接口、自动持久化或表达式执行。

- 上 X／下 X、右 Y／左 Y 可共享尺度。右 Y 独立时可设置一个公共数值，使该数值在左右 Y 轴上的绘图区高度相同；共享和按值对齐互斥，支持线性、Log10、Ln 与反向轴。
- 本阶段参与按值对齐的两根轴均不能属于其他共享组；存在跨层共享时需先解除。分类轴可创建、绑定和共享，但不支持按数值对齐。
- 对齐值输入接受负数、小数和科学计数法。`-`、`.`、`1e-` 等未完成文本会保留在当前属性草稿中，并在补全前禁止“应用”和“确定”。

- 本阶段不包含 X:Y 数据比例以及“应用于”多选／混合值编辑；它们分别归入 F3.4B 和 F3.4C。

验证用例采用左 Y `[0, 0.5, 1]`、右 Y `[0, 500, 1000]`。两条曲线分别绑定左右 Y 轴并在公共值 0 对齐时，应在绘图区得到相同的纵向坐标序列；切换共享后只保留共享范围规则。
