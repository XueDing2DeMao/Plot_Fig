## 功能与入口

| 入口         | 已实现能力                                                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| 出版编辑     | 图例条目选择、排序、行列排版、样例长度、背景和边框；文字、箭头、矩形、参考线的完整样式、位置与坐标空间；预览、应用、取消         |
| 误差编辑     | XY 的 X/Y 对称及非对称误差；分组柱图 valueError；绑定列、颜色、线宽、端帽、显示开关；负值/非法对数误差诊断                       |
| 图层与共享轴 | 复制、删除、排序、网格排版、a/b/c 标签；按全图/行/列/手选共享兼容的数值或分类轴；范围联合包含有效误差端点                        |
| 模板与主题   | 七个内置模板；学术、黑白、色觉友好主题；通用、Nature、IEEE 单/双栏预设；自定义模板保存、重命名、删除、导入导出、标签搜索、缩略图 |

| 出版导出     | SVG、物理尺寸与 DPI 驱动的 PNG、PDF、EPS；默认可编辑文字及可选文字转路径；EPS 明确选择整图栅格化处理透明度                       |
| 批量导出     | 同结构数据表或多个项目；模板预览；独立副本；逐项失败隔离、取消、重试；多格式 ZIP、可选项目 JSON 与 manifest                      |

协议升级为 1.2.0，保留 1.0/1.1 迁移链；项目外壳保持 2.0.0。模板保存在 IndexedDB；项目、模板与导出均使用同一套图形语义。

## 实际浏览器与文件验收

使用本机浏览器访问前端，结合 Inkscape 1.4.4、Ghostscript 10.07.1、Poppler 和 pypdf 验证：

- 恢复双 Panel 项目，保留共享 Y 轴、误差棒、图页图例、箭头及 `Unicode α β 中文`。
- 实际下载 SVG/PNG/PDF/EPS。PNG 为 8592 × 4252，pHYs 为 1199.9976 DPI；PDF MediaBox 为 515.519989 × 255.11811 pt，与 IEEE 双栏 7.16 in × 90 mm 一致。
- 默认 PDF 可提取希腊字母和中文，四个字体子集已嵌入；本机中文使用字体回退。PDF 和 EPS 渲染后均视觉核对了图例、文字、Panel、箭头和误差棒。
- 文字转路径 PDF 的文本提取为空且无字体资源。透明 EPS 默认拒绝；明确栅格化后生成文件并通过 Ghostscript 渲染核对。
- 自定义模板保存后重新打开仍可搜索；重命名、模板 JSON 导出、删除后从导出文件恢复已实际操作。完整四 Panel 模板缺失映射时阻止应用，完成八个字段映射后生成共享范围预览。
- 同结构双表批次中途取消，再重试未成功项，最终 ZIP 包含两项 SVG/PNG/项目 JSON；成功项保持有效。
- 多项目四格式批次：有效项目成功，无效 `kind` 项目失败且保留原因。ZIP 六个成员（四格式、项目 JSON、manifest）与清单逐一对应；PNG 2148 × 1063、299.9994 DPI，PDF 尺寸/Unicode 正确，EPS 文件头有效。
- 390px 视口检查出版编辑、模板库、批次窗口：设置区可滚动，预览可访问，底部操作保持可用，无对话框水平溢出。Escape 关闭后焦点回到入口。

验收临时文件位于被忽略的 `.superpowers/p4-qa/`，浏览器下载位于本机 Downloads。项目不依赖这些文件运行。

## 使用条件与界限

PDF/EPS 需启动[本地转换服务](../packages/export-service/README.md)并填写当次令牌。服务只处理本机数据，不提供远程托管。

LaTeX 标记以原文显示，编辑器提示使用 Unicode；堆叠柱不支持误差棒；Panel 上限 16，批次上限 50，输入合计 100 MiB、输出合计 200 MiB。PNG 最大 64 MP/16384px 边长，DPI 72–2400；PDF/EPS 文字排版受本机字体可用性影响。

期刊尺寸参考 [Nature 官方图形规范](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)与 [IEEE 官方尺寸规范](https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/create-graphics-for-your-article/resolution-and-size/)，核对日期保存在预设中。DPI 和字号范围是编辑建议，不代表自动满足所有目标期刊要求。

生产构建仍有主 JavaScript 分块超过 500 kB 的体积提示；不影响构建和已验证功能。
